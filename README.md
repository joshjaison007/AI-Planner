# Liquid AI

A high-precision productivity interface designed for distraction-free task management.

## Key Features
- **Always-on-Top Distraction-Free Widget:** A compact, floating overlay that tracks your current task in real-time. Designed to keep you focused without needing to keep the full application open.
- **Smart Restoration:** Click the widget at any time to instantly restore the main planner and focus on your active task.
- **Minimalist Aesthetic:** High-precision time tracking with a sleek, premium dark-mode interface.
- **One-Click Navigation:** Quickly jump to "Today" or specific tasks with automatic scrolling and grid alignment.
